### 🛠 Manual HERUKU Setup

#### Step 1: Create Project
- Go to https://railway.app
- Login with GitHub
- Click **New Project**
- Select **Deploy from GitHub Repo**
- Choose `AnnieXMusic`

---

#### Step 2: Add Environment Variables

Go to **HEROKU → Variables** and add:

API_HASH=
BOT_TOKEN=
OWNER_ID=
